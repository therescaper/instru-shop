Mettre les nouveaux prix en ligne

Cette page prépare tes modifications. Elles seront visibles par tous après leur enregistrement sur GitHub, avec ton compte therescaper.

  1. Remplis les prix, puis clique sur Copier mes modifications.
  2. Ouvre l’éditeur GitHub et remplace tout le contenu du fichier par le texte copié.
  3. Clique sur Commit changes, puis confirme. GitHub actualisera la boutique après quelques instants.
